Подготовительный этап:

    Установите сервер MySQL и/или настройте доступ к БД через хостинг.
    Скачайте лабораторный SQL-файл (см. вложение - clients.sql).
    Исполните (импортируйте) его в свою базу данных.

Составьте следующие запросы и проверьте их на практике.

    для поиска по каждому из имен:
    а) Robert,
    б) Jeffrey,
    в) John,
    г) Richard,
    д) David,
    е) по всем этим значениям в одном запросе
    для выборки всех:
    а) женщин,
    б) мужчин
    для определения имени и телефона среди всех клиентов с фамилией:
    а) Williams,
    б) Jones,
    в) Brown,
    г) Miller,
    д) по всем этим значениям в одном запросе
    для определения даты рождения и пола пользователей с именем или фамилией (то есть нужно найти всех пользователей, у которых либо имя, либо фамилия соответствуют заданным):
    а) Kelly,
    б) Thomas,
    в) Clark,
    г) Joseph
    для определения пола, даты рождения и номера телефона пользователей с именем и фамилией:
    а) Tom Brown,
    б) Janet Silberstein,
    в) John Foster

Текст SQL-запросов сохраните в файл и прикрепите его в отклик.
